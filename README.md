# 生活本

微信小程序：打卡 + 美食 / 美容 / 学习。数据仅保存在本机。

## 打开方式

1. 安装微信开发者工具  
2. 导入本项目目录（含 `project.config.json`）  
3. 用测试号 / 游客模式编译  
4. 默认进入 **打卡** Tab  

## V1 结构

| Tab | 内容 |
|---|---|
| 打卡 | 进行中 / 已结束；一键打卡、补卡、结束、继续 |
| 美食 | 搜索；列表=图+名+简介；详情=简介/材料/步骤/注意/评价占位 |
| 美容 | 列表=名称+一行摘要；详情=材料/步骤/注意事项 |
| 学习 | 列表=内容首行；详情=全文 |

从详情可开启打卡（挂到对应笔记上）。

## 开发命令

npm test
