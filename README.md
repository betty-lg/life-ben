# 生活本

微信小程序：把生活笔记（美食做法、护肤方法等）变成可打卡的习惯。数据仅保存在本机。

## 打开方式

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 导入本项目目录（含 `project.config.json`）
3. AppID 可用测试号 / 游客模式（`touristappid`）
4. 编译后默认进入底部 **打卡** Tab

## V1 能力

- **记录**：分类（美食 / 美容 / 健身 / 存款 / 学习）笔记列表；详情以「制作方法」为主；标题旁 ✓ 进入打卡列表
- **打卡**：进行中 / 已结束；一键今日打卡、补卡、结束；非长期打满询问是否继续；长期打满自动续期；已结束可继续打卡
- **本地存储**：清缓存或换机会丢数据；无分享、无推送提醒

## 开发命令

```bash
npm test   # 打卡领域规则单测（不依赖微信运行时）
```

## 目录

- `miniprogram/` 小程序源码
- `tests/domain/` 领域测试
- `docs/plans/` 产品与实现计划
- `prototype/` 交互原型（浏览器）
